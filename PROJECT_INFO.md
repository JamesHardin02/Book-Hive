# Project Info (CSC.289 Capstone)

**Course:** CSC.289 Programming Capstone  
**Term:** Spring 2026  
**Project:** BookHive (Team 1)

## Team & tools

- MS Teams: daily communication + weekly meetings
- Trello: Scrum/Kanban board (Backlog → To Do → In Progress → In Review → Done)
- GitHub: source control, PRs, code review, CI

## Process

We use Agile/Scrum style sprints.

- Sprint planning and review are handled in Teams + Trello.
- Work is done on task branches from `develop`.
- PR review is required before merge to `develop`.
- At the end of each sprint, `develop` is merged into `main`.

## Definition of Done (high-level)

- Acceptance criteria satisfied
- Code formatted + linted
- Tests pass (when applicable)
- Documentation updated (setup and usage)
- PR approved and merged via review process
